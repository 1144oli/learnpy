# 1.3 Your First Project

Our first major Python project will be the game [FizzBuzz](https://en.wikipedia.org/wiki/Fizz_buzz) I think that the wikipedia article explains it quite well: 
>"Players take turns to count incrementally, replacing any number divisible by three with the word "fizz", and any number divisible by five with the word "buzz", and any number divisible by both three and five with the word "fizzbuzz"."

So our expected output would be. 
```
> python3 fizzbuzz.py
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
Fizzbuzz
```
