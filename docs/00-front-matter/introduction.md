# Introduction

Python is one of the most popular languages or even the most popular depending on who you ask. According to the [2025 Stack Overflow Developer Survey](https://survey.stackoverflow.co/2025/technology/) python is the 4th most popular language and only getting bigger, growing by 7 percent form 2024 to 2025 as it's used massively in AI, data science, and back-end development. Python is often the first language people learn as it's considered more simple than "lower level" langauges like C, Rust, or Zig. Python is a scripting language, meaning it is not compillied but is interperated line by line (well theres some nuaunce to this because of CPython but that doesnt really matter right now). 

Python also supports modules and packages, some of which are in the standard library most notabily: random, pickle, tkinter, and os.path. Packages can be installed using a package manager (Shock I know) the most common in Python is pip (we also use pip for libaries outside of the standard library)
