# 1.2 Hello, World!

Most commonly the first thing you write in any programming language you're learning is a hello world program this normally just prints "Hello, World" to the screen and nothing more. 

We use the print() function to print objects to the text stream (like the console) print() is a built in function (you don't have to code it yourself) but it works just as any functions do. To call a function in python we use () and inside these brackets we put arguments, in this case "Hello, World" calling a function is basically running it with the arguments you've set out. Later on you will learn more about how this works in [2.3 Functions](functions.md)

```
print("Hello, World")
```

The quotations denote a string in Python so we use that to type learn more in [2.2 Data types](data-types.md)
